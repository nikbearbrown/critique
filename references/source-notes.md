# Skill sources and selection

The [Bear Brown curated skills](https://www.bearbrown.co/skills) and the [Claude skills directory](https://www.bearbrown.co/claude/skills) are separate catalogs. The second indexes other maintainers' work. An index entry or audit badge is not a recommendation to install or execute it.

## Bear Brown skills

Original guidance below was reviewed in [Bear Brown Tools](https://github.com/nikbearbrown/bear-brown-tools/tree/3a7271fa36955dd6f209fde9232a8992eaefc3a8) (MIT, © 2026 Bear Brown, LLC). The workbench is a newly written adaptation of useful procedures rather than a bundle of the original prompts.

| Source | What Critique uses |
|---|---|
| [Peer Review / CRITIQ](https://www.bearbrown.co/skills/peer-review) | Retained as the general reviewer. Do not install a second copy. |
| [Academic Writing Coach / Bacon](https://www.bearbrown.co/skills/academic-writing-coach) and [Project-to-Scientific-Paper](https://github.com/nikbearbrown/bear-brown-tools/blob/3a7271fa36955dd6f209fde9232a8992eaefc3a8/drafts/project-to-scientific-paper/SKILL.md) | Diagnose first, separate literature gaps from missing methods or data, then plan and draft with resolvable placeholders. No mandatory numeric readiness score or universal journal style. |
| [Science Figure Intelligence / CAJAL](https://www.bearbrown.co/skills/science-figure-intelligence) and [Science Figure Prompts / Figure Architect](https://www.bearbrown.co/skills/science-figure-prompts) | Pick the reader's question, plan visual structure and exclusions, and check proportionality and legibility. Critique adds its own evidence and source checks. Prompt-generated imagery is not data or evidence. |
| [AI/ML Research Paper Analyzer](https://github.com/nikbearbrown/bear-brown-tools/blob/3a7271fa36955dd6f209fde9232a8992eaefc3a8/drafts/aiml-research-paper-analyzer/SKILL.md) | Compare studies by method, result and limitation and give section-level evidence. Avoid fixed topic lists, rigid response layers and claims of exhaustiveness. |
| [Source to Chapter](https://www.bearbrown.co/skills/source-to-chapter) | Apply passage-level provenance to claims. Leave chapter templates and publication automation out. |
| [Graduate Writing Clinic](https://www.bearbrown.co/skills/graduate-writing-clinic) | Useful as an optional coaching register. The existing learner mode already supplies it; no separate reviewer. |

## External references considered

- [AER Skills](https://github.com/brycewang-stanford/aer-skills): evidence and exhibit registers. Do not import discipline-specific identification or journal-compliance claims as general rules.
- [Claude Academic Research](https://github.com/mronkko/claude-academic-research): check source support and separate critique dimensions before reconciliation. No plugin, MCP, citation manager, or automatic network access added.
- [Nature Figure Skill](https://github.com/jing1312/nature-figure-skill): specify the evidence and verify the rendered figure. No publisher endorsement or journal-style compliance promised.

These are method references, not bundled code or runtimes. Provenance, claim status, version pins, evidence limits, and acceptance checks in the workbench are expressed for Critique's existing output and consent rules.
